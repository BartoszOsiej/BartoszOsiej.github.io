04 — Why Slimbook

You build the Linux-first laptop. He's been living the negative of it.

  • Linux ships by default. Every Slimbook arrives with Linux preinstalled and supported — not as a driver lottery he has to win first. His daily driver: Arch + Hyprland, LUKS, kernel-level tracing. A vendor that treats Linux as the product is the only vendor that qualifies.
  • Standard parts. A real upgrade path. SODIMM memory, M.2 storage, replaceable Wi-Fi — the upgrade path the 2017 chassis never had. RAM is the actual ceiling of his career so far; on a Slimbook it is a screw, not a sentence.
  • EU-built, EU-supported. Slimbook builds in Valencia, Spain — EU warranty, EU support, shipping across the Union. Szczecin included.
  • Timing. The current generation is the strongest yet — an Executive 14 or Pro X with real memory headroom. Either one ends the five-year upgrade freeze.
